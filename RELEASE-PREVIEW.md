Unpublished development candidate. The public preview remains 0.2.0-preview.1. The development version is fixed while the main editing path is verified for the beta milestone.

VeyCut 0.3.0 adds selectable export resolutions, with titles and captions rendered at the selected size while preserving the editing project. Export jobs use separate work files and refuse an existing destination, including one created during rendering. Cancellation and project changes discard late progress/results.

Missing-media recovery now searches in the background and can be dismissed. Duplicate filenames and incomplete searches leave paths unchanged. Export resolution controls correctly follow selection and reset. English/Persian installation and editing instructions are in [Quick start](https://github.com/alirezap73/veycut/blob/main/docs/QUICK-START.md). Change interface language in Settings → Language.

The private candidate contains **VeyCut-0.3.0-macos-arm64.dmg** for Apple silicon macOS; it is not a new public release. This is an experimental preview, ad-hoc signed and **not Apple-notarized**. Intel Mac, Windows, Linux and mobile installers are not included. Installation on a separate clean machine, native file-picker/drag/drop and long editing sessions remain unverified.
