VeyCut 0.2.0 adds a caption workspace, WebVTT interchange, group timing/style edits, Unicode find/replace, an embedded Persian font and portrait/square/landscape project formats.

This preview targets Apple silicon macOS. Linux native tests, macOS compilation, wasm lints and the Mac candidate build must pass before its draft is created. Runtime and package-build source must match the native validation revision; later workflow and release-documentation changes are recorded explicitly in VALIDATION.json. Windows validation is tracked separately and Windows installers are excluded. GitHub Actions retains form screenshots, Persian text examples and a bilingual 720p video for review.

The macOS app is ad-hoc signed; it is not notarized with an Apple developer identity. Installation on a separate clean machine, native file-picker/drag-and-drop flows and long editing sessions still need verification. Windows, Linux installers and mobile packages are not included in this preview. This is an experimental preview, not a stable installer release.

The source revision is recorded in manifest.json. SHA256SUMS covers the package and manifest. Source and license notices, including font licenses, are included with the app and repository.
