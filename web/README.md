# VeyCut Web prototype

Open `index.html` in a modern browser, or serve this directory as static files. No package install, build, CDN, external service or network media upload is required. When the server builds `pkg/veycut_web.js` and its Wasm binary, the prototype loads the actual shared Rust editing engine. The badge exposes `data-engine="wasm"` only after module initialization and project creation succeed. Import, trim, split, remove and Undo/Redo use shared commands/history; saved JSON includes the real `engineDocument`. Without that package, a disclosed functional JavaScript fallback remains available. Neither mode claims native feature parity.

Import local browser-decodable video, select a timeline clip, seek using the native video controls, trim source in/out points, split, remove, Undo/Redo and preview consecutive clips. Save project JSON to download the edit description. Open it later and reconnect each selected offline clip using the original filename/size. Media itself is never embedded in JSON. SRT files must be UTF-8, at most 1 MiB, with standard `HH:MM:SS,mmm --> HH:MM:SS,mmm` timings; preview overlapping cues, edit text and export SRT. Import replaces the caption set in one undoable edit. English/Persian UI uses the language selector.

Only project JSON and SRT export are implemented. There is no video render/export, waveform, effects, transitions, audio mixing or model integration. The sequential single-track preview follows native browser playback and may have gaps at clip changes; it is not a frame-accurate compositor. Subtitle times stay fixed in global timeline seconds when video clips change. Codec support depends on the browser. The local probe measures duration and video dimensions only; source frame rate and audio-stream presence are unknown and are not supplied as measured metadata to the shared engine. Its required audio boolean is supplied as false to represent unprobed metadata; native browser preview can still play audio from the file. Shared trimming can leave a leading timeline gap, which the timeline clock retains; the sequential preview does not render black gap frames. Imported file URLs last only for this page session. Undo history is bounded to 100 edits; JavaScript fallback clip/media count to 2000 (the shared bridge caps 128 media items and 512 clips), caption count to 5000, JSON input to 2 MiB and source duration to 24 hours. The portable browser envelope includes media-reconnection metadata and, in Wasm mode, a native engine document. Opening a JavaScript-only envelope retains fallback mode. Captions currently use the browser subtitle layer; they are not added to the shared engine document. Direct desktop project import is not implemented.

No local browser/server/build testing has been performed during this implementation. Required server checks: native file selection, supported/unsupported media, in/out and interior split bounds, selection and atomic Undo/Redo, consecutive preview, offline JSON reopen/reselection and mismatch rejection, malformed/oversized JSON/SRT, literal Persian/English overlay, SRT round-trip, keyboard focus, mobile layout, and object URL cleanup. Do not describe static review as a tested browser release.
